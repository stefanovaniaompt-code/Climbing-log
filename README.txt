CLIMBING LOG — INSTALLAZIONE ANDROID

CONTENUTO
- index.html: app
- manifest.webmanifest: configurazione PWA
- sw.js: funzionamento offline
- icon-192.png / icon-512.png

INSTALLAZIONE CONSIGLIATA
1. Pubblica questa cartella su un hosting HTTPS statico (es. GitHub Pages, Netlify, Cloudflare Pages).
2. Apri l'indirizzo con Chrome su Android.
3. Menu Chrome > "Aggiungi a schermata Home" / "Installa app".
4. Dopo il primo caricamento l'app funziona anche offline.

IMPORTANTE
- I dati sono salvati localmente nel browser/dispositivo.
- Usa periodicamente "Backup > Esporta backup".
- Se cancelli i dati del browser senza backup, il diario può andare perso.

TRAZIONI
Inserisci:
- peso corporeo del giorno del test
- zavorra aggiunta nella 1RM dinamica

Formula predefinita:
carico esterno target = 0,70 × (peso corporeo + zavorra 1RM) − peso corporeo.

BLOCK LIFT
1RM iniziale impostata: 50,4 kg.
Carichi calcolati automaticamente per 60, 65, 70, 75 e 85%.
